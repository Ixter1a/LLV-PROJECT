# LLV · Смены

Панель для работников на FunPay: кто на смене, сколько штук продал, оборот в рублях и чистыми 10%.

Расширение ставится в Chrome. На FunPay по центру появляется кнопка «Начать смену». Уже лежащие на экране заказы не считаются. Новые оплаченные и закрытые заказы в рублях уходят на панель. Возврат вычитается. Смена живёт, пока её не завершат.

День, неделя и месяц считаются по Владивостоку. Неделя начинается в понедельник.

## Почему это не страница GitHub

GitHub Pages отдаёт только файлы. Принять продажу от расширения и сохранить её ему некуда. Поэтому панель — маленький сервер со своей базой: на опубликованном сайте это Postgres, локально — файл `data/store.json`.

## Запуск у себя

```bash
npm install
SITE_PASSWORD='пароль владельца' npm start
```

Сайт откроется на `http://127.0.0.1:8787`. Пароль в код не записан: его задают переменной `SITE_PASSWORD`. Он нужен только владельцу панели и сохраняется в виде хеша. Общего ключа для расширения больше нет.

В панели впишите имя человека и нажмите «Ключ». Ключ показывается один раз и работает только для этого имени. Его вставляют в настройках расширения. «Ключ» у уже созданного человека выпускает новый и гасит старый. «Свой вход» добавляет отдельный пароль панели, чтобы не делиться паролем владельца.

## Расширение

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. «Загрузить распакованное» и укажите папку `extension`.
4. В настройках расширения впишите адрес панели и личный ключ из панели.
5. Откройте FunPay — по центру будет «Начать смену».

Кнопка «Вручную» нужна, если заказ не подхватился сам. «Не сейчас» прячет окно до следующей загрузки страницы.
