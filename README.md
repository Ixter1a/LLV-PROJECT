# LLV · Смены FunPay

Статичный сайт и расширение Chrome для учёта смен на [FunPay](https://funpay.com/). Сотрудник включает смену на странице, которую уже открыл. Расширение читает видимые завершённые заказы (штуки и сумму в рублях) и пишет их в Supabase. Сайт показывает сотрудников, смены, выручку и чистую прибыль — 10% от выручки.

Пароль входа на сайт: `LLVPASSWORD`.

Пока в `js/config.js` пусто или стоят плейсхолдеры, сайт открывается в демо-режиме и показывает пример: **21 штука**, **20 000 ₽** выручки, **2 000 ₽** прибыли. Если расширение уже записало смену на этом компьютере, вместо примера показываются эти локальные цифры. В базу они не уходят, пока не заданы ключи.

## Локально

Из корня репозитория:

```bash
python3 -m http.server 5173
```

Откройте `http://127.0.0.1:5173/`. Сначала введите неверный пароль — появится «Неверный пароль». Затем `LLVPASSWORD`.

## Supabase

1. Создайте бесплатный проект на [supabase.com](https://supabase.com/).
2. Откройте **SQL Editor**, вставьте весь файл `supabase/schema.sql` и выполните его.
3. В **Project Settings → API** скопируйте **Project URL** и **anon public** key. Ключ `service_role` не нужен и в сайт его класть нельзя.
4. Впишите их в `js/config.js`:

```javascript
window.LLV_CONFIG = {
  SUPABASE_URL: "https://YOUR_PROJECT_REF.supabase.co",
  SUPABASE_ANON_KEY: "YOUR_SUPABASE_ANON_KEY"
};
```

Замените оба плейсхолдера. Если хотя бы один останется пустым или с текстом `YOUR_`, сайт останется в демо-режиме.

В базе три таблицы: `workers`, `shifts`, `sales`. Прибыль 10% на сайте считается из `amount_rub`. В `sales.net_rub` то же правило лежит вычисляемой колонкой, отдельно её не вводят.

Anon key попадёт в статический сайт и в расширение, поэтому он публичный. Политики в схеме разрешают этому ключу читать и записывать только эти три таблицы.

## GitHub Pages

Сайт — это файлы в корне репозитория (`index.html`, `css/`, `js/`, `assets/`). Сборка не нужна.

1. Залейте ветку с заполненным `js/config.js` (или оставьте плейсхолдеры, если нужен только демо-режим).
2. В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch**.
3. Ветка `main`, папка **`/ (root)`**, сохраните.
4. Через минуту сайт откроется по адресу `https://<user>.github.io/LLV-PROJECT/`.

Файл `.nojekyll` уже лежит в корне, чтобы GitHub не прогонял страницу через Jekyll.

## Расширение

Каталог `extension/` — Manifest V3.

1. Chrome: `chrome://extensions`.
2. Включите **Режим разработчика**.
3. **Загрузить распакованное** и выберите папку `extension`.
4. Откройте всплывающее окно расширения (или страницу параметров) и вставьте тот же URL и anon key. Chrome спросит доступ к хосту Supabase — разрешите.
5. Откройте `https://funpay.com/` под своим аккаунтом. Над вашими лотами появится карточка **«Управление лотами»**: поиск, **«Начать смену»**, **«Поднять все предложения»** и **«Выбрать лоты»**. «Выбрать лоты» отмечает лоты в таблице и открывает ряд команд, справа кнопка **«Готово»**. Если имени в шапке нет, появится поле. Покупки расширение не делает и пароль FunPay не читает.
6. Пока смена идёт, кнопка называется **«Завершить смену»**. Расширение смотрит заказы, которые уже видны на странице: статус «Закрыт», «Выполнен» или «Подтверждён», число штук и сумма в рублях. Новые такие заказы уходят в Supabase. Уже лежавшие на странице заказы без времени после старта смены не перечитываются.
7. **«Завершить смену»** закрывает смену.

Если URL и ключ не заданы, события копятся в `chrome.storage` на этом компьютере, а на кнопке написано, что они ещё не отправлены. После сохранения ключей нажмите **«Отправить очередь»**. Для локальной проверки подойдёт адрес `http://127.0.0.1` или `http://localhost`.

Иконка сайта и расширения — `assets/icon.png` и `extension/icons/`. Это белый знак на прозрачном фоне; в интерфейсе он лежит на чёрной плашке. Если файл не загрузится, вместо него рисуется белая метка из CSS.

Команды видят только лоты текущего аккаунта и делают то, что уже можно сделать руками на этой странице. «Поднять все предложения» нажимает кнопку «Поднять», если она есть. «Включить», «Выключить» и «Удалить» нажимают такие же кнопки у отмеченного лота. «Клонировать» и «Дублировать» отправляют форму редактирования (у дубля в названии « копия»). «Изменить цену» меняет цену и описание. «Замена в названии» сначала показывает пару «было / стало», затем успех или ошибку по каждому лоту. Поиск оставляет на странице только подходящие свои лоты. Кнопка «⋮» скрывает карточку. Чужие лоты и кнопка «Купить» не используются. Пароль FunPay расширение не читает.
