# LLV · Смены FunPay

Статичный сайт и расширение Chrome для учёта смен на [FunPay](https://funpay.com/). Сотрудник включает смену на странице, которую уже открыл. Расширение читает видимые завершённые заказы (штуки и сумму в рублях) и пишет их в Supabase. Сайт показывает сотрудников, смены, выручку и чистую прибыль — 10% от выручки.

Пароль входа на сайт: `LLVPASSWORD`.

На дашборде, кроме сотрудников и истории смен, есть таблица продаж (дата, продавец, штуки, рубли, прибыль 10%), итоги по дням и две простые диаграммы: продажи по дням и по сотрудникам. Заголовки таблицы продаж сортируют каждый столбец. Рядом можно оставить одного сотрудника или свернуть строки по сотрудникам. Без ключей Supabase это демо-режим.

Пока в `js/config.js` пусто или стоят плейсхолдеры, сайт открывается в демо-режиме и показывает пример: **21 штука**, **20 000 ₽** выручки, **2 000 ₽** прибыли. Если расширение уже записало смену на этом компьютере, вместо примера показываются эти локальные цифры. В базу они не уходят, пока не заданы ключи.

## Локально

Из корня репозитория:

```bash
python3 -m http.server 5173
```

Откройте `http://127.0.0.1:5173/`. Сначала введите неверный пароль — появится «Неверный пароль». Затем `LLVPASSWORD`.

## Supabase

1. Создайте бесплатный проект на [supabase.com](https://supabase.com/).
2. Откройте **SQL Editor**, вставьте весь файл `supabase/schema.sql` и выполните его.
3. В **Project Settings → API** скопируйте **Project URL** и **anon public** key. Ключ `service_role` не нужен и в сайт его класть нельзя.
4. Впишите их в `js/config.js`:

```javascript
window.LLV_CONFIG = {
  SUPABASE_URL: "https://YOUR_PROJECT_REF.supabase.co",
  SUPABASE_ANON_KEY: "YOUR_SUPABASE_ANON_KEY"
};
```

Замените оба плейсхолдера. Если хотя бы один останется пустым или с текстом `YOUR_`, сайт останется в демо-режиме.

В базе три таблицы: `workers`, `shifts`, `sales`. Прибыль 10% на сайте считается из `amount_rub`. В `sales.net_rub` то же правило лежит вычисляемой колонкой, отдельно её не вводят.

Anon key попадёт в статический сайт и в расширение, поэтому он публичный. Политики в схеме разрешают этому ключу читать и записывать только эти три таблицы.

## GitHub Pages

Сайт — это файлы в корне репозитория (`index.html`, `css/`, `js/`, `assets/`). Сборка не нужна.

1. Залейте ветку с заполненным `js/config.js` (или оставьте плейсхолдеры, если нужен только демо-режим).
2. В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch**.
3. Ветка `main`, папка **`/ (root)`**, сохраните.
4. Через минуту сайт откроется по адресу `https://<user>.github.io/LLV-PROJECT/`.

Файл `.nojekyll` уже лежит в корне, чтобы GitHub не прогонял страницу через Jekyll.

## Расширение

Каталог `extension/` — Manifest V3.

1. Chrome: `chrome://extensions`.
2. Включите **Режим разработчика**.
3. **Загрузить распакованное** и выберите папку `extension`.
4. Откройте всплывающее окно расширения (или страницу параметров) и вставьте тот же URL и anon key. Chrome спросит доступ к хосту Supabase — разрешите.
5. Значок расширения открывает страницу настроек LLV на `https://funpay.com/`: слева разделы, справа карточка на каждую функцию. Если вкладка FunPay уже есть, она становится активной. Карточка **«Управление лотами»** по-прежнему стоит в колонке предложений, прямо над таблицей, и не висит поверх сайта. В ней поиск, **«Начать смену»**, цель смены, **«Поднять все предложения»**, **«Экспорт лотов»**, **«Импорт лотов»** и **«Выбрать лоты»**. Окна команд открываются внутри карточки. «Выбрать лоты» отмечает свои лоты и открывает ряд команд, справа **«Готово»**. На чужом лоте есть **«Клонировать лот»**. Если имени в шапке нет, появится поле. Покупки расширение не делает и пароль FunPay не читает.
6. Пока смена идёт, кнопка называется **«Завершить смену»**. Расширение смотрит заказы, которые уже видны на странице: статус «Закрыт», «Выполнен» или «Подтверждён», число штук и сумма в рублях. Новые такие заказы уходят в Supabase. Уже лежавшие на странице заказы без времени после старта смены не перечитываются.
7. **«Завершить смену»** закрывает смену.

Если URL и ключ не заданы, события копятся в `chrome.storage` на этом компьютере, а на кнопке написано, что они ещё не отправлены. После сохранения ключей нажмите **«Отправить очередь»**. Для локальной проверки подойдёт адрес `http://127.0.0.1` или `http://localhost`.

Иконка сайта и расширения — `assets/icon.png` и `extension/icons/`. Это белый знак на прозрачном фоне; в интерфейсе он лежит на чёрной плашке. Если файл не загрузится, вместо него рисуется белая метка из CSS.

«Поднять все предложения» и автоподнятие, пока вкладка FunPay открыта, отправляют тот же запрос, что страница продавца: `POST /lots/raise` с `game_id`, `node_id` и, если FunPay просит выбрать разделы, `node_ids[]`. Куки вкладки браузер прикладывает сам. Ключ сессии и пароль расширение не читает. Если на странице нет номеров раздела, остаётся нажатие видимой кнопки «Поднять». «Выбрать лоты» открывает команды над отмеченными своими лотами: «Выбрать все», «Включить», «Выключить», «Изменить цену», «Клонировать лот», «Замена в названии» и «Удалить». «Готово» справа закрывает выбор. «Изменить цену» спрашивает, установить цену, увеличить, уменьшить или округлить. «Экспорт лотов» сохраняет видимые свои лоты в JSON, «Таблица лотов» — в CSV. «Импорт лотов» создаёт новые по первому своему лоту и не меняет старые. «Клонировать лот» на чужой строке создаёт ваш лот с тем названием и ценой, если в разделе уже есть ваш лот. «Замена в названии» сначала показывает пару «было / стало» для названия и для описания каждого отмеченного лота. Цель смены, в рублях, показывает штуки, выручку, прибыль 10% и сколько осталось до цели. «Тихие часы» ставят автоподнятие на паузу между двумя часами. Названия, которые отличаются одним словом, подсвечиваются.

Кнопка **«Ещё команды»** на той же панели включает остальные действия продавца. Они работают на открытой странице FunPay и хранятся в браузере: автоподнятие, уведомление, подсветка своих лотов, значки промо, комиссия и реальная цена, себестоимость, точная цена на форме лота, эмодзи и быстрые сообщения в чате, приветствие, ответ по слову, сообщение после подтверждения, шаблон отзыва, статистика и экспорт заказов, неподтверждённые номера, график, текст для поддержки, экспорт операций со страницы баланса, скрытие баланса, приватность, тёмная тема, свой фон и звук нового заказа. Шаблоны сами не отправляются, пока не включено «Отправлять шаблон самой». Кнопка «Купить» не нажимается. Пароль FunPay и ключ сессии расширение не читает.

## Автоподнятие в фоне

Расписание живёт в service worker (`chrome.alarms`, раз в минуту). Раз в минуту он проверяет три вещи: наступил ли интервал из настроек, не идут ли тихие часы, и был ли подъём раньше. Если пора, он берёт любую открытую вкладку FunPay с разделом лотов — не обязательно активную и не обязательно в текущем окне — и поднимает лоты в ней через `POST /lots/raise`. Вкладку для этого можно свернуть, но браузер должен быть запущен: сайт не даёт делать такие запросы совсем без окна браузера.

Если FunPay отвечает «Подождите N минут», это не ошибка: расширение просто сдвигает следующую попытку и не шлёт уведомление. Настоящие ошибки показываются уведомлением Chrome и всплывающей плашкой на странице. Последний подъём запоминается в `chrome.storage.local` под ключом `llvLastRaise`, поэтому перезапуск браузера не сбрасывает интервал.

Второго таймера на странице нет намеренно: если бы страница и service worker считали сами, лоты поднимались бы дважды.

## Разделы настроек

Страница настроек повторяет набор функций Lite Bot — 11 разделов: **Предложения**, **Сообщения**, **Отзывы**, **Продажи**, **Покупки**, **Финансы**, **Тема**, **Кастомизация**, **Уведомления**, **API** и **Смена**. Внутри — 42 карточки, у каждой переключатель, поле или выбор. Всё хранится в `chrome.storage.local` под ключом `llvSeller` и применяется сразу, без перезагрузки страницы.

Чего здесь нет и не будет: функций, которые в Lite Bot работают через его сервер, — привязки Telegram, баннера и описания профиля для всех пользователей, публичных стилей ников, их нейросети и Golden Key. Заглушек вместо них тоже нет.

**Тема** — восемь тем и двенадцать фонов, включая «жидкое стекло» и видео-обои. **Кастомизация** — своя ширина и плотность, скрытие элементов сайта. **Уведомления** — свой звук для чата и для нового заказа. **API** — подключение Supabase для учёта смен.

## Что не проверено вживую

Выборки разметки написаны по известной структуре FunPay (`.tc-item`, `.tc-row`, `.chat-msg-text`, `/lots/raise`, `/chat/run`), но проверены только на синтетических страницах. Перед рабочим использованием стоит пройти по своим лотам, чату, отзывам и странице заказов и убедиться, что подсветка, реальная цена, статистика и автоответы срабатывают. Если FunPay сменит классы, поправить нужно в одном месте — в начале соответствующего модуля.
